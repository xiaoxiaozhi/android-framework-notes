# Freeform 部分知识点

- Activity 进入 Freeform 模式，相关的 Task 操作，及 Task 大小最终设置
- Freeform 模式会有特定 DecorCaptionView 来控制最大化、关闭等
- Freeform 模式的拖拽移动相关及相关拖动条件限制
- Freeform 模式的拖拽放大缩小相关
