🧭 ATMS / AMS 专题（独立篇）

🧭 ATMS 是什么：ActivityTaskManagerService 的职责、结构与四条入口服务本体
它管的是层级而非 UI：三个 Binder 接口的分工、六个字段的服务结构、与 WMS 共享同一棵树同一把锁、startActivity 四段接力与三处边界、task 复用两个方法、删除三条路径、跨屏 reparent 四跳、dumpsys 三段读法、八个坑与六道实践题。
 🧱 AMS 是什么：ActivityManagerService 的职责、结构与进程生死服务本体
它管的是进程生存而非界面：三个 Binder 接口的分工、六个字段的服务结构、AMS 与 WMS 为何各持一把锁、进程诞生的五跳（AMS → ProcessList → Process → Zygote）、ProcessRecord/ProcessStateRecord 两组状态、OOM adj 与 lmkd 的边界、Service/广播/Provider 三条组件路径、死亡收尾为何要杀进程组、dumpsys 五段读法、八个坑与三道实践题。
