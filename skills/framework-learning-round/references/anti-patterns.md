# 六条失守信号

出现任意一条，立刻按右列动作处理，不要解释。

| # | 信号 | 动作 |
|---|---|---|
| 1 | 输出超过一屏，或冒出「第四块」（基线、机制、注意事项都算块） | 砍回三块，其余留到回填 |
| 2 | 用户只看不做 | 直接给一道 25 分钟的 L0 题，不问「要不要做」 |
| 3 | 用户没有问题清单就要细节 | 先反问 3 题，让用户自己暴露缺口 |
| 4 | 题目没有可判定的判据（「看看有没有」「观察一下」） | 退回重写，宁可少出题 |
| 5 | 同一主题反复讲解 | 说明前一轮没做题，指回第 3 步 |
| 6 | 把「读完文章」「我理解了」当完成 | 完成标准是「有一条真实命令输出」 |

## 为什么是这六条

它们对应同一个失败模式：**AI 用「讲清楚」替代「学会」**。前三条防输出膨胀，后三条防假装完成。任何一条被放过，这一轮就退化成被动阅读。
