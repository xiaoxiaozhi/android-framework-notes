# 调用链的 HTML 色块画法

用户要把调用链放进单文件 HTML 页面（系列篇、轮次页、笔记页）时按这套画，不要交纯纯文本树或截图。

## 结构

- 一条链 = 一张色块卡片：左侧一条 3–4px 彩色竖线作为标识，卡片顶部是「编号 + 一句话主题」标题，正文是等宽字体（`font-family: ui-monospace, Consolas, monospace`）的调用树。
- 五种编号各用一种颜色，深浅成对写（`light`/`dark` 两个 CSS 变量或 `prefers-color-scheme` 分支），保证浅色和暗色主题下都看得清。
- 树层级只用 `└─` 加空格缩进表达，每层多三个空格；子行与父行的前缀在同一个 `<pre>` 里，不要用 `<ul>` 嵌套，也不要用 CSS margin 拼缩进——两者在等宽正文里对不齐。
- 卡片底部一行「产出 / 留下什么」：这条链最终改了什么状态、留下什么证据。
- 失败模式单独成卡片，逐行写「键 + `文件:行号` + 断在哪」，不要混进正常链路里，否则读者会把断点当步骤。

## 默认与例外

- 多个入口共用主干时，默认每条链各自一张卡片；只有用户明确要求「合并成一棵树」才画总树（公共主干上分叉处标编号）。
- 卡片间距统一（`margin: 14px 0`），长行用 `overflow-x: auto`，不让页面出现横向滚动。

## 校验

1. 渲染：`msedge --headless=new --disable-gpu --hide-scrollbars --user-data-dir=<临时目录> --screenshot=<png> --window-size=1440,<高> file:///<html 绝对路径>`，路径要 URL 编码。
2. 裁切目标区域再看：`python -c "from PIL import Image; im=Image.open(p); im.crop((x1,y1,x2,y2)).save(q)"`，只目视核这一块——缩进是否逐层递进、卡片间距是否一致、有没有横向溢出。看整页缩略图分辨不出缩进错位。
3. 缩进错位靠改 HTML 里的空格补齐（写脚本批量替换每个 `<pre>` 内的子行前缀），不要靠调 CSS。
