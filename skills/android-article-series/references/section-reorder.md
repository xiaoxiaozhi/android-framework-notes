# 单篇 HTML 调整章节顺序

适用：用户说「把 X 节放到最前面 / 这节太靠后 / 顺序不对」，指系列里某一篇正文的章节。

## 步骤

1. 备份原文件（同目录 `*.bak-<时间戳>` 或临时副本），再动内容。
2. 用脚本整块移动 `<section id="...">…</section>`，不要手工剪贴：正则匹配到 `</section>` 边界易错。
3. **重排 `span.num` 序号**：移动后按新顺序从 00/01 依次写回，序号与位置一致。
4. **`section id` 保持原值不动**：id 是锚点键，改了会让外部/内部旧链接失效；标题编号变了、id 不变是正常的。
5. 同步三处非正文内容：
   - 顶部导航 / TOC 的条目顺序；
   - 正文里的交叉引用（「再回头看 0X 的两段骨架」这类），改成被引用章节的新编号；
   - 若有「上一篇/下一篇」或阅读路径说明，按新顺序重写。
6. 回读校验（不要只看脚本 exit code）：
   - 打印每个 `<section id>` 在文件中的出现顺序 + 其 `span.num`，确认两列一致；
   - `grep` 一遍旧编号引用是否残留（如 `num">04` 已变 `num">05`）；
   - Edge headless 截图首屏（`--headless=new --screenshot --window-size=1440,3000 file:///...`），确认新放最前的内容真的出现在 hero 下方第一屏，再回报。

## 回报格式

给用户新顺序清单（编号 + 标题），并列出顺带改掉的三类引用，说明锚点未变。
