# HTML 落盘生产规范

SKILL.md Step 7 的展开。**说「落盘」就直接写正式文件，没有 `_draft`、没有第二阶段。**

## 1. 解析目标目录（写之前）

按顺序：① 用户本次指定目录；② 工作区里与主题匹配、含 `index.html` 或路线图的系列目录（按 `*WMS*`、`*窗口*`、`*显示*`、`roadmap*` 等关键词找）；③ 都没有 → 用当前目录并先问一句放哪。

## 2. 一次口令 = 一份正式文件

- 「落盘 / 出稿 / 生成 HTML」即授权写文件，不再追问确认，不先生成草稿。
- 属于既有系列：扫描该目录现有命名（如 `android-window-NN-主题.html`），**取最大编号 +1**，路线图有预告主题就沿用预告名。编号有歧义（同号/空档/疑似改名）先一句话确认再写。
- 不属于系列：描述性文件名 `主题.html`。
- 写完立刻：告知完整路径 → 用浏览器打开 → 跑第 5 节验收。
- 用户事后要改，直接改这份正式文件。

## 3. 同步更新系列结构

- `index.html`：加入新篇卡片/链接。
- 相邻篇：新篇的上一篇补上「下篇」链接；新篇自身 footer 写上/下篇 + 路线图链接。
- 只有跨多篇的结构调整才参考 android-article-series 技能；本篇质量自检在本技能内完成。

## 4. 成品要求

### 4.1 模板
- 直接复制 `../assets/template.html` 填内容，**不再每篇去逆向旧文章的 CSS**。系列有强制约定（localStorage key、特殊类名）时只覆盖对应变量，主体不动。
- `<title>中文标题 — <实际源码版本> 源码深度分析</title>`，版本以本次读到的源码树为准。

### 4.2 结构
- **长文/系列篇有头有尾**：开篇一段话（覆盖是什么/用在哪/设计取舍/机制骨架，**不拆四个小标题**）→ 0.0 名词表 → 驱动机制 →「方法逐个看」表（方法/类/谁调它/作用/下一步）→ 分块正文 → 稳态闭环 → footer。
- **短篇轻量**：开篇一段话 + 1-3 个代码块 + 结论；名词表/方法表/闭环可省，开篇不能省。
- 每篇独立成篇，前篇只做延伸阅读。

### 4.3 视觉硬要求（模板已内置，不要改回白底）
- 暖色纸张背景 + 深墨色目录/调用树；标题衬线、强调色赤陶；禁止纯白背景。
- 深/浅主题：`[data-theme="dark"]` 变量 + 右下角悬浮按钮 auto→light→dark，默认 auto，每分钟按时间切换；localStorage key 沿用目标系列现有值（窗口系列为 `awt_theme`），新系列用 `awt_theme`。
- 字体栈末尾必须有 `"Segoe UI Symbol","Apple Symbols"`，否则 ①②③▶─ 在 Windows 上渲染偏小。
- 类名：`.card` `.code-block` `.filename`（写 `文件:行号`）`.annotation` `.tag` `.tree`，代码注释用 `<span class="cm">`，章节 `<h2 id="pN">`。
- 调用链用 `.tree` 的 `├─/└─` 树 + 右对齐 `[文件:行号]` + 行内 `//`，不要箭头长句、不要 step-box。
- 思考题：`<details><summary>题目</summary><div class="ans">参考答案/留空</div></details>`；章标题 `🧠 自测：N 个问题`。
- footer：上/下篇 + 路线图链接 + 下篇预告；独立篇只留路线图。

## 5. 验收（不过不许说完成）

在技能目录下运行（路径按实际目标/源码根替换）：

```powershell
# 1) 锚点批量审计：所有 文件.java:行号 必须在源码树里核到
python scripts\audit_anchors.py --html "<成品.html>" --root "<AOSP源码根>"

# 2) HTML 结构/TOC/站内链接
python scripts\check_html.py --html "<成品.html>"

# 3) Edge headless 截图，肉眼确认无白底、无溢出
powershell -File scripts\shot.ps1 -Uri "file:///D:/path/成品.html" -Out "_build\shot.png"
```

- 锚点：输出 `通过 n/n`，必须 **n/n 全过**；有未过项先回源码核实再改文。
- 结构：0 错误；TOC 锚点全部命中 id；站内 .html 链接全部存在。
- 截图：暖色背景、代码块不溢出、目录树对齐。
- 大文件（>8KB）可先在 `_build\` 分块拼接（UTF-8 无 BOM）、抽 JS 跑 `node --check`；`_build\` 只是暂存，成品直接写目标目录，提交后清掉 `_build\`，**严禁把 _build 内容当 _draft 交付**。

## 6. 常见失败模式

- 忘了更新 index / 相邻篇链接 → 系列断链。
- 续编号只看文件名不看路线图预告 → 重号或主题错位。
- 抄旧文章样式时把旧的错误锚点一起抄来 → 必须重 grep。
- 分段并行生成正文 → 禁止；一个叙述者从头写到尾。
