00 窗口为什么是一棵树：DisplayArea 层级入门零基础
从日常屏幕覆盖关系切入，建立"窗口是一棵树"的直觉：layer 与 Feature 两个前置概念、树如何长出来、新窗口如何挂树，以及概念到源码的对照。
 01 窗口树全景：WindowContainer 家族、Z 序与 Token核心概念
窗口是什么、WindowContainer 家族（RootWindowContainer → DisplayContent → DisplayArea → Task → ActivityRecord → WindowState）、窗口树的两层含义、DFS 与 Z 序的关系。
 02 窗口树是怎样建起来的：DisplayAreaPolicyBuilder 构建算法核心算法
三阶段构建（搭骨架 → 开门禁 → 挂叶子）、DisplayAreaPolicyBuilder 的 Feature / PendingArea / 三层遍历算法、窗口如何挂树。
 03 窗口刷新：布局、Z 序与事务提交核心流程
WindowSurfacePlacer 总调度（defer / 最多 6 轮）、forAllWindows DFS 遍历、布局与遮挡检测、assignChildLayers 两遍 Z 序算法、一笔事务提交 SurfaceFlinger。
 04 像素怎样上屏：SurfaceControl、BLAST 与 SurfaceFlinger 合成图形链路
挂树只挂逻辑身份，画布在哪里？relayout 触发 SF 建 BufferStateLayer、SurfaceControl 跨进程过河、App 经 BLASTBufferQueue 把 View 树画进 GraphicBuffer，SF 在 VSYNC 里 commit/composite/present，HWC 与 GPU 合成后交面板扫描发光。
 05 输入事件的分发与窗口命中：InputDispatcher 全链路核心流程
手指点下去，事件怎么沿同一棵窗口树找到目标窗口：InputChannel 电话线、InputMonitor 把可输入窗口表交底给 InputDispatcher、touchable region 命中测试与遮挡判断、焦点、socketpair 分发到 ViewRootImpl，以及两种输入 ANR（窗口无响应 / 无焦点窗口）。
 06 窗口的诞生：从 addView 到窗口上树生命周期
App 侧 WindowManagerGlobal#addView → 一次 binder → system_server 准入审查 → WindowState 挂进 WindowContainer 树；含 BadTokenException 完整因果链与 6 道自测。
 07 窗口的来路与归途：Activity 启动链与窗口生命周期生命周期
补上 06 篇的悬念：ActivityRecord 从哪来、到哪去。startActivity → ActivityStarter 决策 → ActivityRecord（= WindowToken）→ 启动窗口（splash/快照）→ isDrawn 翻转 → 删除三条路径（多任务移除 / 后台 kill / 正常 finish）对比。
 08 窗口的尺寸与身体：布局、Insets 与旋转布局
03 篇的下半场：每一遍遍历到底算了什么。performLayoutNoTrace 与 mPerformLayout、computeFrame 与 DisplayPolicy、Insets 三件套与控制权、旋转冻结/解冻六条件、配置变更谁重建。
 09 窗口动画与过渡：AppTransition 与 leash 缰绳动画
窗口树的第三种改造方式——临时插入 leash 中间层。AppTransition 状态机与 336ms、SurfaceAnimator.startAnimation、createAnimationLeash 的 reparent、WindowAnimator 每帧推进、Shell 接管与远程动画；含完整九步链路。
 10 显示子系统的节拍：vsync 与 Choreographer图形地基
读 03/04/09 篇时处处撞见的两个词，其实都不在窗口树里。按依赖顺序补齐六层：vsync 是什么（中断采样 + 软件预测模型）、为什么有 app/sf 两条相位、EventThread 如何按连接分发、三层「按需」如何让静止画面零唤醒、Choreographer 的 doFrame 五段式、WMS 如何在 android.anim 线程用 getSfInstance 接进来；附 dumpsys 与 Perfetto 排障抓手。
 13 画中画 PiP：一次跨 ATMS / WMCore / WM Shell 的窗口模式迁移窗口模式
专题补篇。从 Activity.enterPictureInPictureMode() 走到 onPictureInPictureModeChanged() 的完整七跳：ACC 硬校验、ATMS 状态门禁与锁屏分叉、RootWindowContainer 搬 Task（单/多 Activity 两条分支）、PipTransition 的 leash 动画与 finish WCT、配置下发后的回调。含归属分层表与小窗三块归属（task 画面 / Shell 逻辑 / overlay 菜单）、退出路径、AOSP 12 与 13 差异、四类现场故障定位。
 14 Winscope 里的图层是什么：Layer、名字、id 与树→图层工具 + 源码
把 SurfaceFlinger trace 的 LayerProto 和 AOSP 12 源码逐条对上：Layer::sequence 怎么发号、SurfaceControl 名字怎么变成 LayerProto.name、assignChildLayers 两遍怎么排 Z，以及 WMS 树如何在 SF 里投影成 Layer 树；附可交互的「层级树 → 图层」编译器。
